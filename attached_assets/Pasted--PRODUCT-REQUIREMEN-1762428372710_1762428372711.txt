================================================================================
1. VISÃO GERAL DO PRODUTO
================================================================================

1.1 OBJETIVO
Criar uma plataforma de e-commerce moderna e intuitiva para venda de camisas 
de futebol autografadas e colecionáveis, oferecendo uma experiência de 
navegação superior com design contemporâneo e sistema de filtragem avançado.

1.2 PÚBLICO-ALVO
- Colecionadores de memorabilia esportiva
- Fãs de futebol (18-55 anos)
- Investidores em itens esportivos de valor
- Presentes para entusiastas do esporte

================================================================================
2. DESIGN E EXPERIÊNCIA DO USUÁRIO
================================================================================

2.1 PRINCÍPIOS DE DESIGN
- Moderno e Minimalista: Design limpo com foco no produto
- Visual Premium: Refletir o valor dos itens colecionáveis
- Responsivo: Experiência perfeita em desktop, tablet e mobile
- Performance: Carregamento rápido de imagens e interações fluidas

2.2 PALETA DE CORES SUGERIDA
- Primária: Azul escuro profundo (#0A1628) ou preto (#000000)
- Secundária: Dourado/Bronze (#D4AF37) - transmite exclusividade
- Accent: Verde vibrante (#00FF87) ou vermelho (#FF3B30)
- Neutros: Cinzas modernos (#F5F5F7, #E5E5EA, #8E8E93)
- Background: Branco puro (#FFFFFF) ou cinza claríssimo (#FAFAFA)

2.3 TIPOGRAFIA
- Headings: Fonte sans-serif moderna (ex: Inter, Manrope, Outfit)
- Body: Fonte legível (ex: System UI, Inter, Roboto)
- Preços: Fonte com peso bold para destaque

================================================================================
3. ESTRUTURA DO SITE
================================================================================

3.1 HEADER (NAVEGAÇÃO SUPERIOR)

Elementos:
- Logo (esquerda) - clicável para home
- Menu principal centralizado ou esquerda:
  * Camisas por Liga (dropdown)
  * Camisas por Clube (dropdown)
  * Seleções Nacionais
  * Novidades
  * Promoções
- Ícones de ação (direita):
  * Busca (com autocomplete)
  * Conta/Login
  * Favoritos (com contador)
  * Carrinho (com contador e preview hover)

Design:
- Sticky header com background blur ao scroll
- Animações suaves nos dropdowns
- Breadcrumbs abaixo do header nas páginas internas

3.2 PÁGINA PRINCIPAL (LISTAGEM DE PRODUTOS)

Layout de Produtos - Grid Responsivo:
- Desktop: 3-4 colunas
- Tablet: 2-3 colunas
- Mobile: 1-2 colunas
- Espaçamento generoso entre cards

Card de Produto:
┌─────────────────────┐
│                     │
│   Imagem Produto    │
│   (hover: zoom)     │
│                     │
├─────────────────────┤
│ Badge: AUTOGRAFADO  │
│ Clube / Jogador     │
│ Descrição curta     │
│ CAD $XXX.XX         │
│ [Ver Detalhes]      │
│ ♡ Favoritar         │

Recursos do Card:
- Imagem principal (hover mostra imagem alternativa)
- Badge visual para "Autografado", "Edição Limitada", "Novo"
- Ícone de favoritos (funcional)
- Quick view modal (ao clicar)
- Indicador de disponibilidade
- Rating/Reviews (se aplicável)

6. RECURSOS AVANÇADOS DE UX
================================================================================

6.1 FILTROS INTELIGENTES
- Auto-atualização: Resultados atualizam sem reload
- Contador de resultados: Mostrar quantos itens em cada opção de filtro
- Desabilitar opções: Filtros que resultariam em 0 produtos ficam disabled
- Persistência: Manter filtros ao navegar entre páginas
- URL amigável: Filtros refletidos na URL para compartilhamento

6.2 BUSCA AVANÇADA
- Autocomplete com sugestões
- Busca por:
  * Nome do jogador
  * Nome do clube
  * Liga
  * Temporada
  * Número da camisa
- Histórico de buscas
- Buscas populares

6.3 WISHLIST/FAVORITOS
- Salvar produtos favoritos
- Sincronização entre dispositivos (login)
- Notificações de redução de preço
- Compartilhar wishlist

6.4 COMPARAÇÃO DE PRODUTOS
- Selecionar até 4 produtos para comparar
- Tabela comparativa side-by-side
- Destacar diferenças

6.5 RECOMENDAÇÕES PERSONALIZADAS
- "Você também pode gostar"
- "Produtos similares"
- "Completam o look" (shorts, meias)
- Baseado em histórico de navegação

================================================================================
7. PÁGINA DE DETALHES DO PRODUTO
================================================================================

7.1 LAYOUT

Duas colunas:

ESQUERDA (60%): Galeria de imagens
- Imagem principal grande
- Thumbnails abaixo ou ao lado
- Zoom ao hover
- Lightbox ao clicar
- 360° view (se disponível)

DIREITA (40%): Informações
- Breadcrumb
- Nome do produto (H1)
- Badge de autenticidade
- Preço destacado
- Opções:
  * Seletor de tamanho (visual)
  * Quantidade
- Botões de ação:
  * Adicionar ao carrinho (primário)
  * Adicionar aos favoritos
  * Compartilhar
- Informações de entrega
- Formas de pagamento aceitas

7.2 SEÇÃO DE DETALHES (ABAIXO)

Tabs:
1. Descrição: História da camisa, contexto
2. Especificações: Tamanho, material, temporada, etc.
3. Autenticidade: Certificado, procedência
4. Entrega e Devolução: Políticas
5. Avaliações: Reviews de clientes

13. ESPECIFICAÇÕES DE CONTEÚDO
================================================================================

13.1 FOTOGRAFIA DE PRODUTOS
Mínimo 5 fotos por produto:
1. Frente sobre fundo branco
2. Costas sobre fundo branco
3. Detalhe do autógrafo (se aplicável)
4. Etiqueta/tag
5. Certificado de autenticidade

- Resolução mínima: 2000x2000px
- Formato: WebP com fallback JPG

13.2 DESCRIÇÕES
- Título otimizado para SEO (60 chars)
- Descrição curta (160 chars)
- Descrição longa (300-500 palavras)
- Especificações técnicas completas
- História/contexto do item
